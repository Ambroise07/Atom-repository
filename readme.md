# ATOMizer of project's creation
ATOM is a framework that helps you create quickly the structure of your project.
It comes with a template that contains the basic.

# project creation:
To create a project, run :
``` python run.py  ```
then follow instructions.

# create project in the current worky directory
You can also create your project inside your current worky directory :
```python main.py --name "my_first_project" ```
